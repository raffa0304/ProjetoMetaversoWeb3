🎮 Projeto VR - Unity

Projeto desenvolvido em Realidade Virtual (VR) utilizando a engine Unity, com foco em interação imersiva e navegação em ambiente 3D.

---

🧠 Sobre o Projeto

Este projeto explora conceitos de desenvolvimento em Realidade Virtual, incluindo:

- Interação com objetos em VR
- Movimentação do jogador
- Ambiente 3D imersivo
- Interface adaptada para VR

O objetivo é criar uma experiência virtual interativa utilizando dispositivos compatíveis com VR.

---

🛠️ Tecnologias Utilizadas

- Unity (Game Engine)
- META SDK
- OpenXR
- Visual Studio Code

---

🥽 Requisitos

Para executar o projeto:

- Unity Hub instalado
- Unity versão recomendada: "2022.x LTS" ou superior

---

🚀 Como Executar

1. Clone o repositório:

git clone https://github.com/raffa0304/ProjetoMetaversoWeb3.git

2. Abra o Unity Hub
3. Clique em Open Project
4. Selecione a pasta do projeto
5. Abra a cena principal em:

Assets/Scenes

6. Pressione ▶ Play ou faça o Build para o dispositivo VR.

---

📁 Estrutura do Projeto

Assets/           → Scripts, modelos e cenas
Packages/         → Dependências do Unity
ProjectSettings/  → Configurações do projeto
